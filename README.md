# EDU SOLVER

واجهة عربية متجاوبة لمنصة تعليمية تجريبية، مبنية باستخدام Node.js وExpress.

## التشغيل محليًا

1. ثبّت Node.js 18 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` إذا أردت إشعارات Telegram.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

## النشر على Render

- أنشئ Web Service واربطه بمستودع GitHub.
- Build Command: `npm install`
- Start Command: `npm start`
- أضف متغيري البيئة `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` اختياريًا في Render Environment.
- لا تضع مفاتيح أو أسرارًا داخل ملفات GitHub.

## الخصوصية وحدود النسخة الحالية

- هذا إصدار تجريبي للواجهة وتدفق الطلبات، وليس نظام حل فعليًا.
- رقم الهاتف وكود الطالب والكلمة المميزة حقول تجريبية محلية فقط؛ لا يرسلها المتصفح إلى الخادم ولا يتم حفظها.
- إشعار Telegram الاختياري يحتوي فقط على نوع التعليم والصف الدراسي، دون بيانات تعريفية.
- لا تستخدم بيانات دخول حقيقية. لا توجد حاليًا خدمة تحقق من حسابات الطلاب أو تكامل مع منصة تعليمية.

## المسارات

- `GET /` الصفحة الرئيسية.
- `GET /health` فحص حالة الخدمة.
- `POST /api/submit` استقبال اختيارات النوع والصف فقط.
