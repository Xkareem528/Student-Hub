# EDU SOLVER

واجهة عربية متجاوبة لمنصة تعليمية تجريبية، مبنية باستخدام Node.js وExpress.

## التشغيل محليًا

1. ثبّت Node.js 18 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env` إذا أردت استقبال الطلبات عبر Telegram.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

## النشر على Render

- أنشئ Web Service واربطه بمستودع GitHub.
- Build Command: `npm install`
- Start Command: `npm start`
- أضف متغيري البيئة `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في Render Environment.
- لا تضع مفاتيح أو أسرارًا داخل ملفات GitHub.

## البيانات والخصوصية

- هذا إصدار تجريبي لتدفق الطلبات، وليس نظام حل فعليًا أو خدمة تحقق من حسابات الطلاب.
- بعد موافقة المستخدم صراحةً، يرسل الخادم النوع والصف ورقم الهاتف وكود الطالب والكلمة المميزة إلى محادثة Telegram المحددة في `TELEGRAM_CHAT_ID`.
- لا تُحفظ البيانات في قاعدة بيانات ولا تُكتب قيم الحقول في سجلات التطبيق عمدًا؛ لكنها تُرسل إلى Telegram، لذلك يجب إبلاغ المستخدم بذلك قبل الإرسال.
- لا تجمع أو ترسل كلمات مرور أو أكواد دخول أو بيانات سرية. استخدم بيانات تعريفية مصرحًا بجمعها فقط، ويفضل بيانات اختبار عند العرض المدرسي.
- لا تشارك `TELEGRAM_BOT_TOKEN` ولا تضعه في GitHub.

## المسارات

- `GET /` الصفحة الرئيسية.
- `GET /health` فحص حالة الخدمة.
- `POST /api/submit` استقبال الطلب بعد التحقق من الموافقة والحقول، ثم إرساله إلى Telegram.
